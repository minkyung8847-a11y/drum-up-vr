# VR 심벌 애니메이션

2026-11-09. 하이햇과 크래시의 시각 동작만 변경한다. 현재 8개 레인, 키트 배치/크기/앉은 높이, 곡/오프셋/판정/입력/진동은 유지한다.

## 구조와 안전한 닫힘

vrCymbalMotion.ts는 기존 hit/raycast 메시를 고정된 기준면으로 보존한다. 같은 geometry를 공유하는 시각용 상단 심벌과 기존 테두리를 cymbal-lift → cymbal-wobble 자식으로 묶는다. 새 geometry/texture를 매 타격 또는 프레임에 생성하지 않는다. 네온/타격 파동도 시각용 심벌의 자식이므로 함께 이동한다. 아래 심벌 및 스탠드는 움직이지 않는다. dispose는 기준면 가시성과 기존 테두리를 복구한다.

닫힘 위치는 고정 아래 심벌의 로컬 림 높이와 위쪽 토러스 두께(.0012), 여유(.00015)로 계산한다. 닫힌 상태에서 위 림의 하단이 아래 림에 거의 닿는다. 흔들림의 최대 하강량 radius*sin(tilt)만큼만 안전 높이를 보정해 관통을 막는다. 반대쪽 틈도 CLOSED 진폭 제한으로 아주 작게 유지한다. 부모 좌표계의 축을 따라 위 심벌만 움직이며 원래 키트의 기울기를 보존한다.

## 조절 상수

VR_CYMBAL_MOTION에 라디안/초/모델 로컬 단위로 모아 둔다.

|상태|충격 진폭|각주파수|감쇠|최대 기울기|
|---|---|---|---|---|
|하이햇 OPEN|.075|26|5.5|.11|
|하이햇 CLOSED|.002|38|18|.003|
|크래시|.14|20|3.2|.22|

감쇠 진동을 해석식으로 적분해 프레임 속도에 따른 불안정을 방지한다. X/Z 두 축의 탄성 모션과 속도에 충격을 더해 반복 타격도 각도를 리셋하지 않고 이어진다. 매 프레임 원점에서 회전을 재구성하며 아주 작은 잔진동만 0으로 정리한다. 크래시는 약 2~3초 잔진동, OPEN 하이햇보다 약 2배 큰 첫 흔들림이다.

닫힘 .09초 / 열림 .13초 smoothstep. 닫힘 완료 시 .055초 동안 .0005의 위쪽 접촉 진동을 추가한다. 기존 왼쪽 squeezestart/squeezeend 및 기존 OPEN/CLOSED/페달 사운드 경로는 변경하지 않는다.

## 검증

npm run test:vr:cymbals: 실제 메시 림 좌표로 OPEN/CLOSED 간격 및 반복 타격 중 관통 방지, 감쇠 진폭/지속, 충격 연속성, 150회 열고닫기 후 무표류, 아래 심벌/충돌 기준면 고정, 네온 부모 관계, 사운드 매핑, dispose, 모의 XR 왼쪽 Grip 닫기/놓기. 두 상태의 동일 카메라 이미지도 생성한다.

Windows Edge의 실제 Three/WebGL + 모의 XR 검사다. 실제 Quest 3에서의 진폭 체감/USB/렌더링 성능은 실기 검증하지 않았다.
