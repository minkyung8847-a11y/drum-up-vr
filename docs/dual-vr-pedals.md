# VR 좌·우 페달 연결

왼쪽은 하이햇 상태, 오른쪽은 킥 타격이다. 현재 장치가 없어도 PC의 `#/pedal` 화면에서 테스트할 수 있다.

- 왼쪽을 밟고 있는 동안 하이햇이 닫히며 스틱 타격은 닫힌 하이햇 샘플을 사용한다.
- 왼쪽을 떼면 하이햇이 열리며 스틱 타격은 오픈 하이햇 샘플을 사용한다.
- 누를 때 오픈 하이햇 잔향을 끊는 페달 샘플을 재생한다. 소리가 잠겨 있어도 시각적 상태는 바뀐다.
- 오른쪽을 밟으면 기존 킥 사운드와 페달·비터·드럼 모션을 한 번 재생한다.
- 연결이 끊기거나 VR 연결을 종료하면 기본 드럼세트의 기본값인 닫힘 상태로 되돌린다. 연결 중에는 1초마다 왼쪽 상태를 다시 보내 패킷 손실 후에도 복구한다.

## 연결과 장치 설정

VR 화면의 **VR pedals**에서 릴레이 서버 주소와 연결 코드를 만들고, PC의 `#/pedal` 화면에서 같은 주소·코드로 연결한다. VR에서 **소리 활성화**를 누른다. 로컬 개발은 `ws://127.0.0.1:8787/pedal`과 `npm run pedal:server`를 사용한다. 독립형 헤드셋에서는 두 장치가 접근할 수 있는 실제 WSS 서버와 배포된 프런트엔드가 필요하다.

| 입력 방식 | 왼쪽 하이햇 | 오른쪽 킥 |
| --- | --- | --- |
| USB 키보드형 | Z 키 누름·해제 | Space 키 누름 |
| USB MIDI | CC 4, 기본값 0~63 닫힘 / 64~127 열림. 번호·경계값·방향을 화면에서 바꿀 수 있음 | Note On 35/36 기본값, 기존 노트 학습 지원 |
| WebHID | 왼쪽 reportId·byte·mask·pressed 값 설정, 보고서의 누름·해제 상태 사용 | 기존 오른쪽 reportId·byte·mask·pressed 값 설정, 누름 가장자리 사용 |

화면의 **왼쪽 밟기 · 닫힘**, **왼쪽 떼기 · 열림**, **TEST KICK** 버튼으로 장치 없이 두 경로를 확인할 수 있다. MIDI CC의 극성이나 HID 보고서 값은 실제 장치 사양에 맞춰 설정해야 한다. 3.5mm 페달은 호환되는 USB 입력 장치 또는 드럼 모듈을 통해 PC가 키보드·MIDI·HID로 인식해야 한다.

현재 소스는 연결 준비와 로컬 테스트까지 구현됐다. 실제 물리 페달, 헤드셋, 외부 WSS 서버에서의 동작과 지연은 장비를 연결한 뒤 확인해야 한다.
